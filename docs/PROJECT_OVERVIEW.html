โตทัน (Totan)

Bone Age Assessment System · NSC 2026 · Project Documentation

🩻 ระบบทำอะไร

โตทัน คือระบบประเมินอายุกระดูก (Bone Age Assessment) สำหรับเด็ก ใช้ในสถานพยาบาล

  • แพทย์ อัปโหลดภาพ X-ray มือเด็ก → AI วิเคราะห์อายุกระดูก (bone age) และทำนายส่วนสูงสูงสุด (FAH) → แพทย์ดูผลและส่งคำแนะนำให้ผู้ปกครอง
  • ผู้ปกครอง รับคำแนะนำและติดตามพัฒนาการเด็ก
  • ระบบเปรียบเทียบกับ Thai Growth Standards 2564 และคำนวณ percentile / Z-score

🔄 Flow หลัก (End-to-End)

แพทย์ — Login
เข้าสู่ระบบด้วย email/password
POST /auth/login → gateway → auth-service → JWT
แพทย์ — เพิ่มเด็ก
บันทึกข้อมูลเด็ก ชื่อ วันเกิด เพศ ส่วนสูงบิดา-มารดา
POST /children → gateway → patient-service → postgres-patient
แพทย์ — อัปโหลด X-ray
สร้าง assessment พร้อม URL ภาพ X-ray และข้อมูลวัดตอนตรวจ
POST /assessments → status: PENDING → call ai-service (non-blocking) → status: PROCESSING
AI Service — ประมวลผล (Background)
Download X-ray → รัน pipeline → callback ผลกลับ
DeepLabV3 → YOLOv11 → ConvNeXt Tiny → Grad-CAM → TW3 → Thai Growth Standards
Patient Service — รับผล AI
บันทึก bone age, percentile, FAH, risk flag → publish event
status: COMPLETED → Redis: "assessment.completed"
Notify Service — แจ้งเตือน
รับ event จาก Redis → ส่ง email แพทย์ + push notification ผู้ปกครอง
TODO: @nestjs/mailer + firebase-admin
แพทย์ — ดูผลและส่งคำแนะนำ
ดูกราฟ FAH/TH, bone age, percentile → เขียนคำแนะนำส่งผู้ปกครอง
GET /assessments/:id → POST /recommendations → Redis: "recommendation.sent"
ผู้ปกครอง — รับการแจ้งเตือน
อ่านคำแนะนำจากแพทย์ ติดตามพัฒนาการเด็ก

📧 Email Verification (OTP)

Frontend — Register
กรอกฟอร์มสมัครสมาชิก → POST /auth/register
auth-service — สร้าง OTP
สร้างเลข 6 หลัก (100000–999999) → บันทึกลง DB พร้อม expiry 10 นาที → status = unverified
Math.floor(100000 + Math.random() * 900000)
nodemailer — ส่งอีเมล
ส่ง OTP ผ่าน Gmail SMTP (port 587 STARTTLS) ด้วย App Password
non-blocking — register ไม่ fail ถ้า SMTP error
Frontend — OTP Screen
แสดง 6 boxes กรอก OTP → POST /auth/verify-email
auth-service — เช็ค OTP
ตรวจ (1) OTP ตรงกับ DB (2) ไม่หมดอายุ → status = active → clear OTP → auto-login → dashboard
nodemailer คืออะไร

library Node.js ที่ทำหน้าที่แทน email client — เชื่อมต่อ SMTP server และส่งอีเมลด้วย code แทนการกดส่งมือ

Gmail App Password คืออะไร

รหัส 16 ตัวที่ Google ออกให้แทน password จริง สำหรับ app ที่ไม่รองรับ 2FA โดยตรง — ต้องเปิด 2-Step Verification ก่อน
